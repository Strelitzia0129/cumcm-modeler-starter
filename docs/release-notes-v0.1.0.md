# v0.1.0 — Initial public release

首个公开版本提供一个可以离线使用、可以持续贡献的 CUMCM 建模手入门工具包。

## Highlights

- 21 张按问题本质组织的算法卡，支持搜索和题型筛选。
- 34 条官方或权威资料入口，记录访问日期和许可提示。
- 30 天冲刺计划、比赛开局协议和 2026 AI 使用留痕模板。
- 可安装的 Python 包：熵权-TOPSIS 和 OAT 敏感性分析。
- 扩展示例覆盖回归、分类、聚类、优化、图论与时间序列。
- 8 个单元测试、离线仓库审计、GitHub Actions CI 和 Pages 部署。
- MIT License、贡献指南、安全政策、Issue/PR 模板和引用元数据。

## Install

```bash
python -m pip install .
cumcm-starter check-env
cumcm-starter demo --out demo_output
```
