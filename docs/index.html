10 分钟选型法

赛题一到手，禁止先搜“高级算法”。按这五步走，20 分钟内应能确定第一版基线。

先判是否需要建模若只是题给公式代入、乘加或确定性核算，直接计算，不强行套模型。
写清输出连续值、类别、排名、最优方案、轨迹/物理量，分别指向不同问题族。
看数据与约束样本量、时间顺序、标签、非线性、整数变量、网络结构和不确定性。
先跑最低基线可解释且能验证：线性回归、朴素预测、LP、简单 ODE、K-Means 等。
用失败证据升级只有残差、约束、非线性或稳定性暴露问题时，才升级复杂模型。

题目要你输出先归类为第一基线必须验证
一个连续数值/未来数值回归 / 时间序列线性/岭回归；朴素法/ETS样本外误差、残差、时间切分

得分、排名、择优综合评价熵权-TOPSIS + 等权对照正向化、权重扰动、排名稳定性
分配、排程、路径、最优方案优化 / 图论LP/MILP/最短路约束残差、最优性界、基线对比
状态随时间/空间变化机理 / ODE/PDE守恒关系 + 简化 ODE量纲、初边值、极端情况、参数敏感性
显著性、影响因素统计推断 / 关联检验 + 回归/相关前提、效应量、混淆、因果边界

这些用法会直接拉低论文可信度

把下面九条贴在比赛桌上。

小样本直接神经网络，既不稳定也难解释。
时间序列随机打乱训练/测试，产生未来信息泄漏。
小规模整数问题不求精确解，先上 GA/PSO。
AHP、熵权、TOPSIS 串联就称“组合创新”。
只报 R²/准确率，不给样本外误差和基线。
优化结果不检查约束违反量和现实可执行性。
插值用于数据区间外，并把它称为预测。
把相关性、Granger 先后关系直接写成因果。
AI 生成的公式、代码、数字未复算且未留痕。
